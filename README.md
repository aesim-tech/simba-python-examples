# simba-python-examples
Collection of sample Python scripts and notebooks using SIMBA's Python API (aesim.simba)

## What is SIMBA?
SIMBA is a modern and powerful Power Electronics simulation environment.
➡ https://www.simba.io

## SIMBA Python API 
The Simba Python Library (aesim.simba) is a Python package that contains hundreds of functions providing direct access to SIMBA such as creating a circuit, modifying parameters, running a simulation, and retrieving results. __aesim.simba__ is independent and does not require to have SIMBA installed to be used.
➡ https://pypi.org/project/aesim.simba/

## Technical studies built with the Python API
Engineering studies published on simba.io, each run with SIMBA through Python (sweeps, Monte Carlo, electro-thermal):
- [IGBT Heatsink Sizing: Why 25 °C Losses Mislead](https://www.simba.io/publications/igbt-heatsink-sizing-electro-thermal-simba/) — coupled electro-thermal sweep of a 6 kW IGBT buck, code included
- [Validating Power Converter Designs with Monte Carlo Analysis](https://www.simba.io/publications/monte-carlo-power-converter-validation/)
- [Sensitivity Analysis Using SIMBA](https://www.simba.io/publications/sensitivity-analysis-with-simba/)
- [How Fast Can You Build an Operating Map of a Buck Converter?](https://www.simba.io/publications/buck-converter-operating-map-simba/)
- [Observing Magnetic State Variables in a Forward Converter](https://www.simba.io/publications/magnetic-core-forward-converter-simba/)

➡ All publications: https://www.simba.io/publications/
